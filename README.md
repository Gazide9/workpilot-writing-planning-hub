# Workpilot Writing Planning Hub

Writing

Role

Act as an expert UI/UX designer and full-stack developer specializing in AI-powered web applications.

Objective

Develop WorkPilot AI, a productivity website that generates professional emails, creates prioritized daily and weekly schedules, and provides an interactive AI workplace chatbot.

Context

The website targets professionals, students, and businesses who want to improve productivity and manage work efficiently. Use a modern SaaS design with navy blue, white, and purple accents, responsive layouts, and intuitive navigation.

Requirements

Smart Email Generator: Generate emails in formal, friendly, and persuasive tones, with options to edit, regenerate, and copy.

AI Task Planner: Create and manage tasks, prioritize deadlines, and generate daily or weekly schedules.

AI Chatbot: Handle user prompts, answer workplace questions, draft emails, summarize text, and assist with planning.

Dashboard: Display tasks, upcoming deadlines, productivity statistics, and quick-access tools.

Design and Technology: Use React or Next.js, TypeScript, Tailwind CSS, and secure AI API integration. Include responsive design, authentication, and data storage where available.

Output

Deliver a professional, responsive, and functional AI workplace assistant website integrating all three tools into one platform, with interactive components, secure AI functionality, and a clean, user-friendly interface.
